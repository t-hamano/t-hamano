## MarkBricks

**A visual Markdown editor powered by the WordPress block editor experience.**

- Block-based editing for Markdown files, with your original syntax preserved
- Monaco source mode, live Mermaid / KaTeX previews, Marp slides
- Desktop app (Windows / macOS / Linux) and VS Code extension

[Website](https://t-hamano.github.io/mark-bricks/) &nbsp;·&nbsp; [GitHub](https://github.com/t-hamano/mark-bricks)

## WordPress Plugins

I currently maintain six plugins on [WordPress.org](https://profiles.wordpress.org/wildworks/).

| Plugin | Description |
| --- | --- |
| [Flexible Table Block](https://wordpress.org/plugins/flexible-table-block/) | Table block with cell merging, detailed styling, and responsive support |
| [Custom HTML Block Extension](https://wordpress.org/plugins/custom-html-block-extension/) | Turns the Custom HTML block into a Monaco-based code editor with Emmet |
| [Flexible Spacer Block](https://wordpress.org/plugins/flexible-spacer-block/) | Spacer block with separate heights for desktop, tablet, and mobile |
| [Enable Responsive Image](https://wordpress.org/plugins/enable-responsive-image/) | Adds per-breakpoint image sources to the Image block |
| [RichText Extension](https://wordpress.org/plugins/richtext-extension/) | Adds highlighter, font size, and more formats to the RichText toolbar |
| [Piano Block](https://wordpress.org/plugins/piano-block/) | Play the piano inside the block editor |
